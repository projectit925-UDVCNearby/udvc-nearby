# UDVC Nearby

ระบบแนะนำสถานที่ที่พักและร้านอาหารรอบวิทยาลัยอาชีวศึกษาอุดรธานี
โครงงานนักศึกษา ปวช.3 แผนกเทคโนโลยีสารสนเทศ ภาคเรียนที่ 2/2569 (ไม่ใช่เว็บไซต์ทางการของวิทยาลัย)

## ฟังก์ชัน
- แผนที่ปักหมุดที่พัก (สีน้ำเงิน) และร้านอาหาร (สีส้ม) พร้อมวงรัศมี 500 ม. / 1 กม. รอบวิทยาลัย
- ค้นหาชื่อ / เมนู และตัวกรอง งบ ประเภทหอ แอร์ ระยะทาง
- การ์ดรายละเอียด ค่าห้อง ค่าน้ำไฟ ห้องว่าง ระยะเดิน รูปภาพ ปุ่มนำทาง Google Maps
- หน้าแอดมิน (`admin.html`) เพิ่ม แก้ไข ลบ ข้อมูลและอัปโหลดรูป

## เทคโนโลยี
- HTML, CSS, JavaScript
- [Leaflet](https://leafletjs.com/) + OpenStreetMap (แผนที่)
- [Supabase](https://supabase.com/) (ฐานข้อมูล PostgreSQL, ระบบล็อกอิน, เก็บรูป)
- GitHub Pages (ฝากเว็บ)

## โครงสร้างไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html`, `css/style.css`, `js/app.js` | หน้าแผนที่สำหรับผู้ใช้ |
| `admin.html`, `css/admin.css`, `js/admin.js` | หน้าแอดมิน |
| `js/supabase-config.js` | ค่าเชื่อมต่อ Supabase และพิกัดวิทยาลัย |
| `supabase/*.sql` | คำสั่งสร้างตาราง กฎความปลอดภัย และข้อมูลตัวอย่าง |

## ผู้จัดทำ
- นายโอเปมิโป โจเซฟ อดิกัน
- นายไวภพ วรยันต์
- นายคมกฤต มาพระยืน
- นายรัฐภูมิ ทองสุข
